# 💳 RiseFinance

Landing page moderna desenvolvida para uma fintech fictícia, com foco em design elegante, experiência do usuário e interface responsiva.

O projeto foi criado utilizando HTML e CSS, inspirado em layouts modernos de startups e plataformas financeiras.

---

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Flexbox
* Google Fonts
* Figma

---

## ✨ Funcionalidades

* Header responsivo
* Hero section moderna
* Sessão de controle financeiro
* Área de crescimento financeiro
* Footer completo
* Layout inspirado em fintechs modernas
* Efeitos hover e transições suaves

---

## 🎨 Objetivo do Projeto

O objetivo deste projeto foi praticar:

* Estruturação semântica em HTML
* Organização de layouts com Flexbox
* Estilização moderna com CSS
* Criação de interfaces inspiradas em UI/UX profissionais
* Desenvolvimento de landing pages responsivas

---
Projeto inspirado em interfaces modernas de fintechs, com visual escuro, elementos em gradiente e foco em experiência visual.
